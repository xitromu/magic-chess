# Волшебные шахматы

Детская игра-обучалка шахматам: дракончик Искра объясняет фигуры, шах и мат, рокировку, пешечный бой.
Всё в одной веб-странице, работает в браузере телефона и компьютера без интернета.
Исходная версия сделана в claude.ai.

## Устройство

| Путь | Что это |
|---|---|
| `game/index.html` | код игры: разметка, стили, логика, тексты фраз |
| `game/clips.json` | озвучка: фразы (ключ — хеш текста) и звуки `sfx_*` в mp3 |
| `build.py` | сборка офлайн-версии одним файлом → `dist/Волшебные-шахматы.html` |
| `voicekit/` | озвучка фраз на своей видеокарте (см. `voicekit/README.txt`) |

## Как собрать

    python build.py

Готовый файл — `dist/Волшебные-шахматы.html`.

## Как запускать при разработке

`game/index.html` сам подгружает `clips.json` рядом с собой, но браузер разрешает это только через веб-сервер:

    cd game
    python -m http.server 8000

и открыть http://localhost:8000. Если открыть `index.html` двойным щелчком — игра работает,
но вместо записанного голоса говорит встроенный голос браузера.

## Озвучка

Фраза находит свою запись по хешу текста. Если текст фразы изменился — нужна новая запись,
иначе игра прочитает фразу голосом браузера. Новые и изменённые фразы озвучиваются через `voicekit`.
