ОЗВУЧКА «ВОЛШЕБНЫХ ШАХМАТ» НА СВОЕЙ ВИДЕОКАРТЕ
==============================================

Нужно: Windows 10/11 или Linux, NVIDIA RTX (проверено под RTX 50xx: ставится PyTorch с CUDA 12.8),
свежий драйвер NVIDIA, Python 3.11 (python.org, при установке отметить «Add to PATH»),
интернет при первом запуске (скачаются модели, ~3–4 ГБ).

1. УСТАНОВКА (один раз)
   Положите все файлы из архива в одну папку, например C:\voice.
   Двойной щелчок по setup_windows.bat            — голос Silero (быстро, надёжные ударения)
   или в консоли:  setup_windows.bat f5           — ещё и F5-TTS (живее, копирует голос с образца)
   В конце должно быть написано: CUDA: True | NVIDIA GeForce RTX 5060

2. ОЗВУЧКА
   Откройте консоль в этой папке и выполните:
     .venv\Scripts\activate
     python voice_tool.py --from-html Волшебные-шахматы.html --embed-html Волшебные-шахматы.html

   Скрипт сам достанет все фразы из игры, озвучит, проверит распознаванием речи
   и сохранит:
     out\review.html                            — открыть в браузере и послушать (слабые фразы сверху, красным)
     out\clips.json                             — озвучка в формате игры (пришлите мне — вставлю в онлайн-версию)
     Волшебные-шахматы-новый-голос.html         — готовая офлайн-игра с новым голосом
     out\report.csv                             — оценки всех фраз

3. НАСТРОЙКА ГОЛОСА
   --speaker xenia | kseniya | baya | aidar | eugene     голос Silero (добрые: xenia, baya)
   --pitch 1.0         тон; по умолчанию не меняется: сдвиг даёт «трубный» металлический призвук
   --tempo 1.0         темп; то же самое. Для F5 темп лучше менять через --f5-speed (без искажений)
   Сначала попробуйте на нескольких фразах:
     python voice_tool.py --phrases проба.txt --out проба --speaker baya

4. ЕСЛИ СЛОВО ПРОИЗНОСИТСЯ НЕВЕРНО
   Добавьте его в stress.txt (плюс перед ударной гласной: кор+оль) и переозвучьте только эти фразы:
     python voice_tool.py --from-html Волшебные-шахматы.html --only "король"
   Или все слабые:  --redo-below 0.95

5. F5-TTS (самый живой голос)
   Запишите образец 6–10 секунд: чистый голос, без музыки и эха, добрая интонация, wav.
   Лучше свой голос или голос кого-то из близких (с их согласия).
     python voice_tool.py --from-html Волшебные-шахматы.html --engine f5 ^
        --ref-audio образец.wav --ref-text "Точный текст, который сказан в образце."
   F5 делает по 5 дублей на фразу и оставляет лучший по распознаванию.

6. БУДУЩИЕ ВЕРСИИ ИГРЫ
   Запускайте тот же скрипт с новым html. Уже озвученные фразы берутся из out\clips,
   озвучиваются только новые. Ключи фраз совпадают с теми, что ищет игра.

Лицензии: модели Silero и F5-TTS разрешены для некоммерческого использования
(семья, клуб) — для продажи игры нужны другие голоса.
